# Docs

このディレクトリは、スクラッチ日本語SLM開発の作業ドキュメント置き場です。

## 命名ルール

- 通常の作業メモ・調査メモ・進捗ログは、ファイル名の先頭に日付を付ける。
- 継続的に参照する重要ドキュメントは、日付を付けない。

## 重要ドキュメント

- `training-prep.md` - 学習準備の基本方針と進め方
- `corpus-design.md` - corpus設計とmanifest方針
- `gpu-handoff.md` - GPUが空いた後に進むための引き継ぎ

## 日付付きドキュメント
